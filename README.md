# Data Analysis Projects
### About the Project 

This folder includes several Python projects focused on data analysis, visualization, and insights.
Each project explores different datasets and techniques using Pandas, Matplotlib, and Seaborn, with the goal of understanding patterns, trends, and real-world applications of data.

These projects reflect my learning journey in data analytics - from cleaning and transforming raw data to building visual summaries that tell a story.

### 📊 Projects Included

1. Sales Data Analysis (Pandas + Matplotlib)

Analyzes a retail dataset to find:

- Best-performing months and cities for sales
- Most popular product categories
- Correlation between product price and demand
- Overall revenue trends

Skills used: Data cleaning, grouping, merging datasets, visualizing trends
Tech: Python, Pandas, Matplotlib

### 💭 What I Learned

- How to load and clean large datasets using Pandas
- How to create meaningful visualizations to explain trends
- How to draw conclusions from data and present insights clearly
- How to work with real-world data formats (CSV, JSON)

### ⚙️ How to Run

1. **Clone the repository:**
```bash
git clone https://github.com/marrmora/data_analysis_projects.git
cd data_analysis_projects
```

2. **Install the required libraries:**
```bash
pip install pandas matplotlib seaborn jupyter
```

3. **Open the notebook:**
```bash
jupyter notebook pandas-sales-analysis.ipynb
```
### 💻 Tech Stack

- Python 3
- Pandas: data manipulation and cleaning
- Matplotlib & Seaborn: data visualization
- Jupyter Notebook: interactive analysis
